ECOD H-Group Comparison: CIRPIN vs. Progres
============================================

This directory contains data, scripts, and notebooks for evaluating how well
CIRPIN and Progres embeddings separate proteins within ECOD homology groups (H-groups).
The core idea: proteins in the same H-group share homology, so a good structural
embedding should score them highly against each other. We run all-vs-all scoring
within each H-group and find CIRPIN recovers pairs ( > 0.8) that Progres misses in 407/1000 H-groups.

REFERENCE FILES
───────────────
ecod.v294.1.F40.names.txt
    ECOD v294.1 domain names, filtered to 40% sequence identity (F40 rep set).
    Used to map domain IDs to H-group membership.

ecod.v294.1.domains_homology_groups.txt
    H-groups within ECOD.

ecod_dict.json
    Dictionary of ECOD names and pdb file IDs. Generated by
    scripts/create_ECOD_pdb_dictionary.py.

SCRIPTS
───────
scripts/write_structure_lists.py
    # For each homology group file, extract ECOD domain IDs and create a corresponding structure list mapping them to PDB file paths.

scripts/remove_empty_pdbs_from_slist.sh
    Filters structure list files to remove entries pointing to missing or
    zero-byte PDB files. Run before embedding to avoid silent failures.

scripts/embed_and_score_h_group.py
    Core script. For a given H-group, loads structure files, computes CIRPIN
    and Progres embeddings, runs all-vs-all cosine similarity scoring, and
    writes filtered results (pairs above threshold).

scripts/embed_and_score_h_group_savenp.py
    Variant of the above that additionally saves raw all-vs-all score matrices
    as compressed .npz arrays (group_XXXX_all_scores.npz). Use when you need
    the full score distribution, not just filtered pairs.

scripts/embed_and_score.sh
    SLURM wrapper that dispatches embed_and_score_h_group.py (or the _savenp
    variant) across H-groups as array jobs on the cluster.

scripts/cirpin_hits_list_with_ECOD.sh
    Post-processing script. Scans completed group output directories, identifies
    groups with CIRPIN hits (non-empty filtered_results.txt), and writes summary
    files annotated with ECOD group IDs and hierarchy labels (architecture,
    X-group, H-group). Outputs to h_level_results/.

scripts/create_ECOD_pdb_dictionary.py
    Builds ecod_dict.json from the raw ECOD domain tables. Run once when
    updating to a new ECOD release.

H-LEVEL RESULTS
───────────────
h_level_results/sampled_1k_ECOD_h_groups.txt
    Random sample of 1,000 ECOD H-groups used as the evaluation set.

h_level_results/groups_with_hits.txt
    H-groups where CIRPIN found at least one pair above the similarity
    threshold. Tab-separated: group_name, ecod_group (2-level, e.g. 805.1),
    n_pairs, architecture, x-group, h-group.

h_level_results/groups_with_negative_hits_ecod.txt
    H-groups where Progres found hits that CIRPIN missed, annotated
    with their ECOD classification. Same column format as groups_with_hits.txt.
    Used to characterize what kinds of folds CIRPIN misses.

EXAMPLE H-GROUP DATA
─────────────────────
example_h_group_data/ holds four representative H-groups (37, 524, 653, 1238)
with full outputs.

Each group_XXXX/ folder contains:
    embs_CIRPIN.pt              CIRPIN embeddings for all structures in the group
    embs_Progres.pt             Progres embeddings for the same structures
    group_XXXX_all_scores.npz   Full all-vs-all score matrix (CIRPIN vs Progres)
    group_XXXX_filtered_results.txt
                                Pairs passing the similarity threshold, with
                                both CIRPIN and Progres scores

example_h_group_data/structure_lists/
    structure_list_XXXX.txt     Input file listing PDB paths for each example group

TYPICAL WORKFLOW
────────────────
1. write_structure_lists.py        — build per-group PDB lists from ECOD tables
2. remove_empty_pdbs_from_slist.sh — clean lists of missing structures
3. embed_and_score.sh              — run embeddings + scoring on the cluster
4. cirpin_hits_list_with_ECOD.sh   — collect results → h_level_results/
5. ECOD_analysis.ipynb             — analyze and plot
